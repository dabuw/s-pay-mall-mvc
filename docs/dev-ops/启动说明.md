# 本地启动说明

## 前置条件

- Docker Desktop 已启动。
- 已安装 Java 8 和 Maven 3。
- 已在 natapp 创建 HTTP 隧道并将自己的 token 写入
  `docs/dev-ops/natapp/config.ini`。仅调试微信扫码和支付宝异步回调时需要
  启动 natapp。

## 首次启动

在项目根目录依次执行：

```bash
# 构建后端 JAR
mvn clean package -DskipTests

# 构建后端镜像
docker build -t system/s-pay-mall-mvc-app:1.0 \
  -f s-pay-mall-web/Dockerfile s-pay-mall-web

# 启动 MySQL、Redis 及管理工具
docker compose -f docs/dev-ops/docker-compose-environment.yml up -d

# 启动后端和 Nginx 前端
docker compose -f docs/dev-ops/docker-compose-app.yml up -d
```

等待 MySQL 健康检查通过后，再启动应用服务。检查运行状态：

```bash
docker ps
docker logs -f s-pay-mall
```

## 后续启动

镜像已构建且代码未修改时，无需再次执行 Maven 或 `docker build`：

```bash
docker compose -f docs/dev-ops/docker-compose-environment.yml up -d
docker compose -f docs/dev-ops/docker-compose-app.yml up -d
```

停止服务：

```bash
docker compose -f docs/dev-ops/docker-compose-app.yml down
docker compose -f docs/dev-ops/docker-compose-environment.yml down
```

## 访问地址

| 服务 | 地址 |
| --- | --- |
| 前端 | `http://<本机局域网 IP>` |
| 后端接口 | `http://<本机局域网 IP>:8080` |
| phpMyAdmin | `http://localhost:8899` |
| Redis 管理界面 | `http://localhost:8081` |

当前局域网 IP 可通过以下命令查看：

```bash
ifconfig en0 | awk '/inet / {print $2}'
```

前端接口地址在以下文件中配置：

- `docs/dev-ops/nginx/html/login.html`
- `docs/dev-ops/nginx/html/index.html`

如果 Wi-Fi 重新分配了本机 IP，请将这两个文件中的旧 IP 更新为新 IP。
Nginx 挂载了该目录，保存后在浏览器强制刷新即可，无需重启容器。

## 微信和支付宝沙箱联调

启动后端后，在另一个终端运行：

```bash
cd docs/dev-ops/natapp
./natapp
```

natapp 用于让微信和支付宝从公网访问本机后端回调接口。其公网域名应同步
配置到微信公众平台回调地址和应用配置中的支付宝 `notify_url`。

商城微信扫码登录成功后，点击下单会跳转到支付宝沙箱。支付时必须登录支付宝
沙箱提供的买家测试账号；正式支付宝账号无法完成沙箱支付。

## 常见问题

| 现象 | 排查方式 |
| --- | --- |
| 页面无法获取二维码 | 确认后端容器运行，并检查前端配置的局域网 IP 和端口 `8080`。 |
| 扫码后无法回到商城 | 确认 natapp 正在运行，且微信公众平台回调地址使用当前 natapp 域名。 |
| 下单跳转失败 | 确认已使用支付宝沙箱买家账号登录，并检查后端日志。 |
| 后端无法连接数据库 | 执行 `docker ps`，确认 `mysql` 状态为 `healthy`。 |
